# Student Report Automation

An automated student report workflow built using n8n, Google Sheets, Gmail, and AI.

# Overview

This project automates the process of handling student marks and generating student reports. It reduces repetitive manual work by connecting student data with an automated workflow.

# Workflow

Google Sheets → Process Student Data → AI Processing → Generate Report → Gmail

# Technologies Used

* n8n
* Google Sheets
* Gmail
* AI API
* Workflow Automation

# Key Features

* Reads student data from Google Sheets
* Processes student marks automatically
* Uses AI to generate report content
* Automates email delivery
* Reduces repetitive manual work

# Purpose

The purpose of this project is to demonstrate how AI and workflow automation can be used to simplify real-world administrative tasks.
